# Fitness Diet Planner

Fitness and Diet Planner is a cross-platform mobile application developed with React Native (frontend) and Node.js + MongoDB (backend). The app helps users manage their fitness routines and nutrition goals through personalized recommendations and tracking features.

Key Features:

- User registration, login, and profile management

- BMI calculation & categorization with tailored workout recommendations

- Personalized workout suggestions saved daily

- Meal tracking with calorie & macronutrient breakdown (protein, carbs, fats)

- Water intake tracking with daily goal progress

- Personalized diet plan creation based on BMI, TDEE, preferences, and allergies

- API integrations (Tasty API for meals)

- Data storage with AsyncStorage (local) and MongoDB (remote)

- Runs on both Android and iOS



Technologies Used:

- React Native (frontend)

- Node.js + Express (backend)

- MongoDB + Mongoose (database)

- AsyncStorage (local storage)

- Tasty API via RapidAPI (meal data)
